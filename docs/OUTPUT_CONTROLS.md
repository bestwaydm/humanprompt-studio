# Output Controls

HumanPrompt Studio supports two main control layers: Output Goal and Output Style.

## Output Goal

### Improve as Prompt
Turns the input into a stronger prompt ready for another AI tool.

### Generate Final Content
Produces the final content directly instead of a prompt.

### Create Brief + Prompt
Creates a strategic brief and then a final prompt.

### Analyze Request
Explains intent, missing details, risks, and recommendations.

### Create Variations
Creates multiple versions for testing or comparison.

## Output Style

### Direct Prompt
A clean, short, paste-ready instruction.

### Structured Prompt
A clear prompt organized with bullet points and deliverables.

### Short Prompt
A compact version for quick use or tools with limited context.

### Deep Professional Prompt
A detailed expert-level prompt with goals, audience, constraints, quality rules, and deliverables.

### Tool-Specific Prompt
Adapts the output for a selected tool such as Facebook, Canva, Figma, Midjourney, Veo, ChatGPT, Claude, or Gemini.

## English spell correction

The checkbox **Fix English spelling & grammar before enhancing** is enabled by default.

Example corrections:

```text
bussiness -> business
Nusring -> nursing
Intervetions -> interventions
Good Price -> affordable pricing
High Concern -> compassionate care
```

The app keeps the original meaning while making the request cleaner for the selected AI provider.
