# Release Checklist

Before publishing a release:

- [ ] `.env` is not included.
- [ ] `data/ai_providers.json` is not included.
- [ ] `data/prompt_history.json` is not included.
- [ ] No real API keys appear in the repository.
- [ ] No private phone numbers, names, or customer prompts are included in examples.
- [ ] PHP syntax check passes.
- [ ] README is updated.
- [ ] CHANGELOG is updated.
- [ ] Version number is updated in `config/app.php`.
- [ ] Provider Vault works.
- [ ] Local Rule Engine fallback works.
- [ ] Main form works.
- [ ] Copy buttons work.
- [ ] Output Goal and Output Style work.
